# Описание проекта

Проект содержит функции для вычисления площади и периметра
круга и квадрата.

# Math formulas

## Area

- Circle: S = πR²
- Square: S = a²

## Perimeter

- Circle: P = 2πR
- Square: P = 4a

# Описание функций

## circle.py

### area(r)

Вычисляет площадь круга.

Параметр `r` — радиус круга.

Пример вызова:

```python
area(5)
```

### perimeter(r)

Вычисляет периметр круга.

Параметр `r` — радиус круга.

Пример вызова:

```python
perimeter(5)
```

## square.py

### area(a)

Вычисляет площадь квадрата.

Параметр `a` — длина стороны квадрата.

Пример вызова:

```python
area(5)
```

### perimeter(a)

Вычисляет периметр квадрата.

Параметр `a` — длина стороны квадрата.

Пример вызова:

```python
perimeter(5)
```
