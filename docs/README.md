# Geometric Lib

> Python-библиотека для вычисления **площади** и **периметра** геометрических фигур.

---

# Описание проекта

Проект содержит функции для вычисления площади и периметра круга, квадрата, прямоугольника и треугольника. Каждая функция снабжена комментарием с описанием, параметрами, примером вызова и ожидаемым результатом.

## Структура проекта

```text
geometric_lib
├── circle.py
├── square.py
├── rectangle.py
├── triangle.py
└── docs
    └── README.md
```

# Math formulas

## Area

| Фигура | Формула |
|:-------|:--------|
| Circle | S = πR² |
| Square | S = a² |
| Rectangle | S = a · b |
| Triangle | S = a · h / 2 |

## Perimeter

| Фигура | Формула |
|:-------|:--------|
| Circle | P = 2πR |
| Square | P = 4a |
| Rectangle | P = 2(a + b) |
| Triangle | P = a + b + c |

# Описание функций

## circle.py

### area(r)

Вычисляет площадь круга.

Параметр `r` — радиус круга.

Пример вызова:

```python
area(5)
```

Результат: `78.53981633974483`

### perimeter(r)

Вычисляет периметр круга.

Параметр `r` — радиус круга.

Пример вызова:

```python
perimeter(5)
```

Результат: `31.41592653589793`

## square.py

### area(a)

Вычисляет площадь квадрата.

Параметр `a` — длина стороны квадрата.

Пример вызова:

```python
area(5)
```

Результат: `25`

### perimeter(a)

Вычисляет периметр квадрата.

Параметр `a` — длина стороны квадрата.

Пример вызова:

```python
perimeter(5)
```

Результат: `20`

## rectangle.py

### area(a, b)

Вычисляет площадь прямоугольника.

Параметры `a` и `b` — длины сторон прямоугольника.

Пример вызова:

```python
area(5, 3)
```

Результат: `15`

### perimeter(a, b)

Вычисляет периметр прямоугольника.

Параметры `a` и `b` — длины сторон прямоугольника.

Пример вызова:

```python
perimeter(5, 3)
```

Результат: `16`

## triangle.py

### area(a, h)

Вычисляет площадь треугольника.

Параметр `a` — длина основания, `h` — высота, проведённая к основанию.

Пример вызова:

```python
area(6, 4)
```

Результат: `12.0`

### perimeter(a, b, c)

Вычисляет периметр треугольника.

Параметры `a`, `b`, `c` — длины сторон треугольника.

Пример вызова:

```python
perimeter(3, 4, 5)
```

Результат: `12`
